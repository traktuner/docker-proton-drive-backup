**Proton Drive Backup 1.0.1** fixes a memory leak in 1.0.0.

## Fixed

- **Memory use grew during long runs.** Each file and folder that the app read from Drive stayed in memory until the container restarted. In a production install, memory use grew from about 0.7 GB to 1.8 GB in 7 hours. The more files your Drive folders contain, the faster it grew. With 1.0.1, memory use stays at the same level for the whole run.

## Upgrading

Pull the new image and restart the container. You do not have to change your configuration. A backup that was running continues from where it stopped.

## Good to know

`/api/diagnostics` now also shows the number of encryption keys in memory (`caches.keys`) and the time spent in garbage collection (`gc.gcMs`).
